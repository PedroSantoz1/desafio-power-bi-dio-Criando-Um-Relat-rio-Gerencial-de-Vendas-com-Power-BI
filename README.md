# 📊 Relatório Financials — Power BI

Projeto desenvolvido como parte de um desafio prático da **DIO**, utilizando a base **Financial Sample** do Power BI.

O objetivo foi criar um relatório interativo e organizado, aplicando conceitos de visualização de dados, navegação entre páginas e análise de indicadores.

## 🎯 Objetivo do projeto

Desenvolver um relatório mais elaborado no Power BI utilizando a base Financial Sample, buscando facilitar a análise das informações por meio de dashboards interativos.

Durante o projeto foram utilizados:

- 📊 Gráficos e indicadores para análise dos dados
- 🔘 Botões para navegação entre páginas
- 🎛️ Segmentadores de dados
- 🖼️ Botões com imagens
- 🔄 Alternância entre diferentes visuais
- 📑 Múltiplas páginas de relatório
- ☁️ Publicação no Power BI Service

## 📈 Relatório

O dashboard foi desenvolvido para permitir uma visualização mais clara dos principais indicadores da base Financial Sample.

Foram aplicados recursos de interatividade para que o usuário possa filtrar os dados, navegar entre diferentes páginas e visualizar as informações por diferentes perspectivas.

## 📚 Aprendizados

Com este projeto foi possível praticar conceitos importantes do Power BI, como:

- Construção e organização de dashboards
- Escolha e configuração de visuais
- Utilização de segmentadores
- Navegação entre páginas
- Criação de indicadores
- Utilização de DAX
- Organização visual de relatórios
- Publicação de relatórios no Power BI Service
